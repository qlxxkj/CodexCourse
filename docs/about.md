# About Codex Course
## 关于课程

This course is designed for absolute beginners who want to learn how to use OpenAI's Codex — an AI coding agent that can read files, write code, run commands, and automate tasks using natural language.

**No programming experience required.** If you can speak naturally, you can use Codex to complete practical tasks.

### Course Contents
- **Module 1:** Understanding Codex (3 lessons)
- **Module 2:** Getting Started (4 lessons)
- **Module 3:** Core Features (4 lessons)
- **Module 4:** Practical Tips (3 lessons)
- **Module 5:** Project Practice (4 projects)
- **Module 6:** Summary & Next Steps (2 lessons)

### What You'll Learn
- File operations: organize folders, batch rename, classify files
- Natural language programming: describe needs in plain language, let Codex generate code
- Web search: let Codex search the internet and compile reports
- Automation: let Codex handle repetitive tasks
- Skills: use built-in skills to complete complex tasks (like generating PPTs)

### Target Audience
- Professionals with zero programming background
- Content creators who want to automate their workflow
- Anyone who wants to leverage AI for productivity

---

## 课程定位

面向零编程基础的职场人士和内容创作者，让学员理解 Codex 是什么、能做什么，并能独立用 Codex 完成实际任务。

## 课程目标

- 理解 AI 编程助手与聊天机器人的区别
- 掌握 Codex 的安装、登录和基本操作
- 能用自然语言指挥 Codex 完成文件操作、数据分析、网页生成等任务
- 独立完成 4 个实战项目
