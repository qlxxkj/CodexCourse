核心知识点回顾（上）

01
Codex 是什么
OpenAI 的 AI 编程智能体，能读文件、写代码、运行命令、操作文件系统
02
工作区（Workspace）
Codex 操作文件的范围，类似"沙盒"，确保安全和可控
03
权限模式
默认权限（安全）→ 自动审查（高效）→ 完全访问（高风险）
04
Vibe Coding
用自然语言描述目标，指令四要素：动作 + 对象 + 规则 + 期望结果

常见问题排查

问题可能原因解决方案
Codex 无法读取文件工作区未设置或权限不足检查工作区设置，确认权限模式
指令执行结果不符预期指令不够清晰具体使用指令模板，补充背景和验收标准
联网搜索失败网络问题或 API 限制检查网络连接，确认账号额度
文件操作被拒绝默认权限模式下未确认在权限提示中选择"允许"
Codex 响应很慢任务复杂或网络延迟拆分大任务，逐步执行
