模块一

AI 编程助手 vs 聊天机器人

聊天机器人
只能"聊"，不能"干"
你问它问题，它给你文字回复。你可以让它写代码片段，但代码能不能跑、怎么跑、在哪里跑——它不管。
局限性
❌ 不能读你的项目文件
❌ 不能运行代码并调试
❌ 不能操作电脑上的文件
❌ 不能完成完整任务
AI 编程助手（Codex）
能"聊"也能"干"的智能体
不仅回答你的问题，还能直接操作你的文件和系统，完成从需求到交付的全过程。
核心能力
✅ 读你的项目文件
✅ 运行代码并调试
✅ 操作电脑上的文件
✅ 调用外部工具

模块一

Codex 到底是什么？

核心定义
Codex 是 OpenAI 推出的 AI 编程智能体（coding agent）
两个关键词
编程 — 核心能力围绕代码展开：写代码、改代码、调试代码、解释代码
智能体 — 不是被动回答问题的工具，而是能主动执行任务的"助手"
"你不需要教它编程知识，你只需要告诉它你要什么。"
类比：Codex = 会编程的实习生
📌 你告诉它要做什么（用自然语言）
📌 它自己去读相关文件、写代码、运行测试
📌 发现问题 → 修正错误 → 把成果交给你
另一个类比
Codex = 万能秘书
整理文件、搜索资料、写邮件、做表格，额外还会写代码。

模块一

Codex vs GitHub Copilot

GitHub Copilot
代码补全工具 — 给程序员用的"辅助轮"
在编辑器里打字，它帮你补全下一行代码。需要至少看得懂代码。
工作位置
VS Code 等代码编辑器内
任务粒度
单行 / 单函数级别
Codex
完整任务智能体 — 给普通人用的"自动驾驶"
你告诉它"帮我做一个网页"，它会自己读文件、写代码、保存文件，独立完成全过程。
工作位置
独立桌面 App / 命令行
任务粒度
完整功能 / 完整项目

模块一

编程开发案例

案例 1：修 Bug
把报错信息和代码拖进 Codex，说"帮我找原因并修复"，30 秒得到修复方案。
案例 2：从零到网页
告诉 Codex 产品功能，自动生成完整 HTML，30 分钟替代几天的前端工作。
案例 3：重构代码
把混乱的脚本拖进去，Codex 拆分函数、加注释、写文档。
案例 4：Excel 分析
拖入 Excel，Codex 用 Python 读取、分析、生成图表，2 小时变 5 分钟。
KEY
你不需要知道"索引越界"是什么，只需要告诉 Codex "出错了，帮我修"。
WHO
律师、招聘、运营、设计师、教师 — 非技术岗位也在用。

办公提效 & 日常任务

办公提效
整理杂乱的下载文件夹
把"下载"文件夹设为工作区，说"按文件类型分类"，5 分钟搞定几百个文件。
办公提效
生成会议纪要
把会议文字稿发给 Codex，自动生成结构化纪要：议题、讨论要点、待办任务。
办公提效
批量处理 Excel
拖入 Excel，Codex 分析数据并生成图表，2 小时工作变 5 分钟。
日常任务
整理照片 · 分析磁盘空间 · 翻译文档
按 EXIF 日期分类照片、找出占用空间最大的文件、翻译并润色文档。
核心认知
Codex 不是高级搜索工具
它是能直接操作你文件和系统的智能助手——从需求到交付，全程自动化。

Codex vs ChatGPT

ChatGPT 是一辆车，Codex 是这辆车的"自动驾驶模式"。
ChatGPT 普通聊天模式
回答问题、写文案、翻译
不能操作你的文件，不能执行代码。
Codex（代码解释器模式）
读文件、写代码、运行命令
在工作区内直接操作文件系统，能执行代码。
聊天 / 问问题
