# Codex 从零到一：让 AI 帮你搞定编程与办公

> **课程定位**：面向零编程基础的职场人士和内容创作者  
> **课程目标**：让学员理解 Codex 是什么、能做什么，并能独立用 Codex 完成实际任务  
> **课程时长**：建议 5-7 小时（可分模块学习）

---

## 📖 课程简介

你有没有过这样的经历？

- 想写个小工具整理文件，但不会编程
- 要做一份 PPT，从找资料到排版折腾半天
- 想分析一堆数据，Excel 公式翻遍搜索引擎还是搞不定
- 听说 AI 能帮人写代码、做办公，但自己完全不知道从哪里开始

如果你中了一条以上，这门课就是为你准备的。

**Codex 是 OpenAI 推出的 AI 编程智能体（coding agent）**。它不是简单的"聊天机器人"，也不是只会补全代码的工具——它能读你的项目、写代码、运行命令、调用工具，甚至能帮你整理电脑文件夹、生成 PPT、做数据分析。

更重要的是：**你不需要会编程**。只要你会说人话，就能用 Codex 完成这些任务。

OpenAI 内部，律师用 Codex 整理合同条款，招聘人员用 Codex 筛选简历，运营人员用 Codex 做数据报表。你当然也可以。

---

## 🎯 学完这门课，你能做到什么？

| 能力 | 具体表现 |
|------|---------|
| 文件操作 | 让 Codex 帮你整理文件夹、批量重命名、归类文件 |
| 信息检索 | 让 Codex 联网搜索资料并整理成报告 |
| 简单编程 | 用自然语言描述需求，让 Codex 生成网页或小工具 |
| 自动化 | 让 Codex 执行重复性任务，节省时间 |
| 技能调用 | 使用 Codex 内置技能快速完成复杂任务（如生成 PPT） |

## 📚 课程结构

本课程共 **6 个模块**，约 **16 节课 + 4 个实战项目**：

```
模块一：认识 Codex          →  了解它是什么、能做什么
模块二：上手准备            →  安装、登录、第一次对话
模块三：核心功能            →  文件操作、自然语言驱动、联网、自动化
模块四：实用技巧            →  写好指令、安全使用、调用技能
模块五：项目实战            →  4 个完整项目，从入门到进阶
模块六：总结与进阶          →  回顾、常见问题、下一步方向
```

> 💡 **教学提示**：每节课以"先演示、后讲解、再实操"为基本节奏，避免一上来讲原理。

## ⏱️ 建议学习路径

### 完整学习（推荐）
按模块顺序学习，总时长约 **5-7 小时**：

| 模块 | 预计时长 | 说明 |
|------|---------|------|
| 模块一 | 45 分钟 | 建立认知，不用急着操作 |
| 模块二 | 60 分钟 | 动手安装、登录、跑通第一个任务 |
| 模块三 | 90 分钟 | 核心功能，每节课都要跟着实操 |
| 模块四 | 45 分钟 | 技巧提升，边学边用 |
| 模块五 | 120 分钟 | 项目实战，建议分两天完成 |
| 模块六 | 30 分钟 | 回顾和规划下一步 |

### 速成学习
如果时间紧张，可以只学：

1. **模块一**（认识 Codex）→ 15 分钟
2. **模块二**（安装 + 第一次对话）→ 30 分钟
3. **模块五·项目一**（整理电脑）→ 20 分钟

这样你就能用 Codex 做最实用的事情了。

## 🛠️ 课前准备

开始前，请确保你准备好了以下内容：

1. **ChatGPT 账号** — 免费版可用，但建议 Plus/Pro 额度更充裕
2. **一台电脑** — macOS 或 Windows 均可
3. **稳定的网络连接** — Codex 需要联网使用
4. **一个待整理的文件夹** — 用于实操练习（比如"下载"文件夹）
